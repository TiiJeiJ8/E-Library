# Templates

This folder contains templates to help contributors maintain consistency when adding documentation to the E-Library.

## Available Templates

- **book-summary-template.md** - Template for creating book summaries
- **reading-notes-template.md** - Template for creating reading notes
- **genre-readme-template.md** - Template for genre folder README files
- **author-readme-template.md** - Template for author folder README files
- **topic-readme-template.md** - Template for topic folder README files

## How to Use

1. Copy the appropriate template
2. Rename it according to the naming conventions
3. Fill in the sections with your content
4. Save it in the appropriate folder
5. Submit via pull request
