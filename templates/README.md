# Templates

[EN English](./README.md) | [ZH 中文](./README.zh-CN.md)

This folder contains templates to help contributors maintain consistency when adding documentation to the E-Library.

## Available Templates

- [**book-summary-template.md**](./book-summary-template.md) - Template for creating book summaries
- [**reading-notes-template.md**](./reading-notes-template.md) - Template for creating reading notes
- [**genre-readme-template.md**](./genre-readme-template.md) - Template for genre folder README files
- [**author-readme-template.md**](./author-readme-template.md) - Template for author folder README files
- [**topic-readme-template.md**](./topic-readme-template.md) - Template for topic folder README files

## How to Use

1. Copy the appropriate template
2. Rename it according to the naming conventions
3. Fill in the sections with your content (include metadata such as ISBN, Edition, Pages where applicable)
4. Save it in the appropriate folder (book files go under `library/`, indexes live under `books/`)
5. Submit via pull request

### Bilingual Guidance

- Prefer single-file bilingual sections for small pages, or separate `README.md` and `README.zh-CN.md` for larger content. For larger content, split into two files: `README.md` and `README.<language>-<region>.md`.
- Keep metadata consistent across languages.
- Note: At least one version must be in English.
