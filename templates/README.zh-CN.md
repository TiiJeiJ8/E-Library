# 模板

[EN English](./README.md) | [CN 中文](./README.zh-CN.md)

此文件夹包含用于帮助贡献者在 E-Library 中保持文档一致性的模板。

## 可用模板

- [**book-summary-template.md**](./book-summary-template.zh-CN.md) - 创建书籍摘要的模板
- [**reading-notes-template.md**](./reading-notes-template.zh-CN.md) - 创建阅读笔记的模板
- [**genre-readme-template.md**](./genre-readme-template.zh-CN.md) - 类别文件夹 README 模板
- [**author-readme-template.md**](./author-readme-template.zh-CN.md) - 作者文件夹 README 模板
- [**topic-readme-template.md**](./topic-readme-template.zh-CN.md) - 主题文件夹 README 模板

## 使用方法

1. 复制相应的模板
2. 根据命名约定重命名
3. 按模板填写内容（尽量补充元数据，如 ISBN、版次、页数 等）
4. 保存到相应文件夹（书籍二进制文件放在 `library/`，索引位于 `books/`）
5. 通过 pull request 提交

### 双语写作建议

- 内容较少时可在同一文件中分段呈现英语与您的母语两版；内容较多时可分为 `README.md` 与 `README.<language>-<region>.md` 两个文件。
- 两种语言的元数据与关键信息需保持一致。
- 注意！至少一版必须为英语。
