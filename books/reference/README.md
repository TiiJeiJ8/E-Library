# Reference 📚

This folder contains reference materials, dictionaries, encyclopedias, and handbooks.

## Topics Include:

- **Dictionaries**: Language dictionaries, specialized terminology
- **Encyclopedias**: General knowledge, subject-specific encyclopedias
- **Manuals & Handbooks**: User guides, technical references
- **Style Guides**: Writing style, formatting standards
- **Grammar & Language**: Grammar rules, language learning
- **Standards & Specifications**: Technical standards, protocols
- **Glossaries**: Specialized vocabularies and terms
- **Catalogs**: Reference catalogs and indexes
- **Quick References**: Cheat sheets, reference cards

## Naming Convention

Follow the standard format: `Author_Last_Name - Book_Title.extension` or `Title.extension` for general references.

**Examples:**
- `Oxford_English_Dictionary.pdf`
- `Chicago_Manual_of_Style.epub`
- `Strunk_William - The_Elements_of_Style.pdf`

## Subdirectories

Feel free to create subdirectories for better organization:
- `dictionaries/`
- `manuals/`
- `style-guides/`
- `language/`
- etc.
