# 按流派组织的书籍

[🇺🇸 English](./README.md) | [🇨🇳 中文](./README.zh-CN.md)

**说明**：本目录仅作为索引视图。实际电子书文件存放在 [library/](../../library/README.zh-CN.md)。

本文件夹按主要流派组织电子书。每个流派都有自己的子文件夹。

## 可用流派

按需创建流派子文件夹，例如：

- **Fiction** - 小说、短篇与文学作品
- **Non-Fiction** - 传记、随笔与事实类作品
- **Technical** - 编程、工程与技术手册
- **Science** - 科学著作与研究材料
- **Business** - 商业、管理与创业
- **Self-Help** - 个人发展与自我提升
- **History** - 历史文本与纪实
- **Philosophy** - 哲学著作
- **Arts** - 艺术、音乐与创意作品
- **Education** - 教科书与教育材料

## 添加书籍

1. 如果没有，请创建流派子文件夹
2. 将电子书文件按命名规范添加进去
3. 更新流派文件夹的  [README](../../templates/genre-readme-template.zh-CN.md)，列出书籍

## 示例结构

```
by-genre/
├── Fiction/
│   ├── README.md
│   └── Orwell_1984_1949.epub
├── Technical/
│   ├── README.md
│   └── Kernighan_TheCProgrammingLanguage_1988.pdf
└── Science/
	├── README.md
	└── Hawking_ABriefHistoryOfTime_1988.epub
```
