# 按流派浏览

[US English](./README.md) | [CN 中文](./README.zh-CN.md)

此目录按流派组织我们收藏的书籍。每个流派都有一个专门的子文件夹，其中包含一个 `README.md` 文件，列出了 [`../../library`](../../library/README.zh-CN.md) 目录中该类型的所有可用书籍。

## 工作原理

- **流派文件夹**：每个子文件夹都以一个流派命名（例如，`Fiction`、`Technical`）。
- **书籍列表**：在每个流派的文件夹内，一个 `README.md` 文件提供了相关书籍的详细信息和链接。

该系统使您可以根据自己的兴趣发现书籍并探索不同的类别。

## 如何添加流派

1.  **创建流派文件夹**（例如，`Fiction`）。
2.  在新文件夹内**添加 `README.md` 文件**。您可以使用 [`genre-readme-template.zh-CN.md`](../../templates/genre-readme-template.zh-CN.md) 作为起点。
3.  在 `README.md` 中**列出该流派的书籍**，并提供指向 `library` 目录中文件的链接。

## 示例结构

```
by-genre/
├── Fiction/
│   └── README.md  (列出所有小说类书籍)
├── Technical/
│   └── README.md  (列出所有技术类书籍)
└── Science/
    └── README.md  (列出所有科学类书籍)
```

有关浏览馆藏的不同方法的更多信息，请参阅[书籍组织主页](../README.zh-CN.md)。
