# Browse by Genre

[EN English](./README.md) | [ZH 中文](./README.zh-CN.md)

This directory organizes books from our collection by genre. Each genre has a dedicated subfolder containing a `README.md` that lists all books of that type available in the [`../../library`](../../library/README.md) directory.

## How It Works

- **Genre Folders**: Each subfolder is named after a genre (e.g., `Fiction`, `Technical`). Genres can be **nested** to create more specific categories (e.g., `Fiction/Science-Fiction`).
- **Book Lists**: Inside each genre's folder, a `README.md` file provides details and links to the relevant books. For broad genres, this file can also serve as an index for its sub-genres.

This system allows you to discover books based on your interests and explore different categories.

## How to Add a Genre or Sub-Genre

1.  **Create a new folder** inside `by-genre/` or an existing genre folder (e.g., `Fiction` or `Fiction/Science-Fiction`).
2.  **Add a `README.md` file** inside the new folder.
    -   For a **top-level genre**, use the [`genre-readme-template.md`](../../templates/genre-readme-template.md).
    -   For a **sub-genre**, use the [`sub-genre-readme-template.md`](../../templates/sub-genre-readme-template.md) to ensure correct pathing.
3.  **List the books** of that genre in the `README.md`.

## Example Structure

```
by-genre/
├── Fiction/
│   ├── README.md            (Lists all fiction books or serves as an index for sub-genres)
│   ├── Science-Fiction/
│   │   └── README.md        (Lists all science fiction books)
│   └── Fantasy/
│       └── README.md        (Lists all fantasy books)
├── Technical/
│   └── README.md            (Lists all technical books)
└── Science/
    └── README.md            (Lists all science books)
```

For more information on the different ways to browse the collection, see the [main book organization page](../README.md).
