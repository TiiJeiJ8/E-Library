# 怪诞小说（Weird Fiction）

[EN English](./README.md) | [CN 中文](./README.zh-CN.md)

怪诞小说是一种融合恐怖、幻想与超自然元素的流派，旨在营造出一种令人不安与陌生的氛围。它常常探讨宇宙恐怖、未知以及人类理解界限等主题。

## 定义与范围
怪诞小说通常呈现出离奇、超现实或无法用常规解释的超自然元素。它常引起恐惧与不安，挑战读者对现实的认知。

## 收录标准
- 作品应包含恐怖、幻想或超自然元素。
- 应能唤起一种神秘或令人不安的感觉。
- 可以涉及宇宙恐怖、未知或人类理解极限等主题。
- 可收录短篇小说、中篇或长篇小说。
