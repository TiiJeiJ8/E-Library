# 投机小说 / 科幻 (Speculative-Fiction)

[EN English](./README.md) | [CN 中文](./README.zh-CN.md)

本文件夹包含探讨“如果……会怎样”的作品、另类现实与思想实验类小说。

## 定义与范围
投机小说是一种涵盖广泛的虚构文学类别，探讨假设性情境、未来设想或另类现实。它包括科幻、奇幻和其他基于“如果……会怎样”问题的叙事。

## 纳入标准（可选）
- 作品应主要为虚构叙事。
- 作品应探讨假设性或未来情境。
