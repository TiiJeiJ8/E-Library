# Technology 🔧

This folder contains books about technology, IT systems, technical guides, and emerging technologies.

## Topics Include:

- **IT & Networking**: Network protocols, systems administration, cybersecurity
- **Hardware & Electronics**: Computer hardware, embedded systems, IoT
- **Mobile Development**: iOS, Android, mobile app development
- **Cloud Computing**: AWS, Azure, Google Cloud, cloud architecture
- **Cybersecurity**: Ethical hacking, penetration testing, information security
- **Emerging Technologies**: Blockchain, quantum computing, AR/VR
- **Technical Manuals**: Software documentation, tool guides
- **Tech Industry**: Tech culture, startups, innovation

## Naming Convention

Follow the standard format: `Author_Last_Name - Book_Title.extension`

**Examples:**
- `Hunt_Andrew - The_Pragmatic_Programmer.pdf`
- `Kim_Gene - The_Phoenix_Project.epub`
- `Tanenbaum_Andrew - Computer_Networks.pdf`

## Subdirectories

Feel free to create subdirectories for better organization:
- `networking/`
- `cybersecurity/`
- `cloud/`
- `mobile/`
- etc.
