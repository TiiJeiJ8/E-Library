# Computer Science 💻

This folder contains books related to computer science, software engineering, programming, and related topics.

## Topics Include:

- **Programming Languages**: Python, Java, C++, JavaScript, Go, Rust, etc.
- **Software Engineering**: Design patterns, clean code, software architecture
- **Algorithms & Data Structures**: Sorting, searching, graphs, trees, complexity analysis
- **Operating Systems**: Unix/Linux, Windows internals, system programming
- **Databases**: SQL, NoSQL, database design, query optimization
- **Computer Architecture**: Hardware, compilers, computer organization
- **Artificial Intelligence & Machine Learning**: Deep learning, neural networks, ML algorithms
- **Web Development**: Frontend, backend, full-stack development
- **DevOps & Cloud**: Docker, Kubernetes, AWS, Azure, CI/CD

## Naming Convention

Follow the standard format: `Author_Last_Name - Book_Title.extension`

**Examples:**
- `Martin_Robert - Clean_Code.pdf`
- `Cormen_Thomas - Introduction_to_Algorithms.pdf`
- `Gamma_Erich - Design_Patterns.epub`

## Subdirectories

Feel free to create subdirectories for better organization as the collection grows:
- `programming-languages/`
- `algorithms/`
- `web-development/`
- `machine-learning/`
- etc.
