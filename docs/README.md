# Documentation

[EN English](./README.md) | [ZH 中文](./README.zh-CN.md)

This folder contains additional documentation for books in the library, including summaries and reading notes.

## Folders

- **summaries/** - Brief summaries and overviews of books
- **reading-notes/** - Detailed reading notes, insights, and highlights

## Purpose

These documents enhance the usability of the e-library by:
- Helping readers decide which books to read
- Providing quick reference to key concepts
- Sharing insights and perspectives
- Creating a collaborative learning environment

## Contributing

Feel free to add your own summaries and notes! See the templates folder for formatting guidelines.
