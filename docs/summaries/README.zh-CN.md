# 书籍摘要

[EN English](./README.md) | [CN 中文](./README.zh-CN.md)

本文件夹包含库中可用书籍的简要摘要和概述。

## 目的

书籍摘要帮助读者：
- 快速了解一本书的内容
- 判断一本书是否符合他们的兴趣
- 在深入阅读原文之前获得概览
- 回顾自己曾读过的书籍要点

## 格式

每个摘要应包含：
- 书名与作者
- 出版年份
- 主要主题
- 简要概述（3–5 段）
- 目标读者

参见推荐格式模板：[template](../../templates/book-summary-template.zh-CN.md)

## 命名约定

为了支持多语言贡献并明确作者，请使用以下格式命名摘要文件：

**格式**: `作者-书名_出版年份.[语言].md`

-   `[语言]`: 使用双字母语言代码（例如，`en` 代表英语，`zh` 代表中文）。

此约定可确保同一本书的不同语言摘要能够被归类在一起，同时保持区分。

-   **英文示例**: `Orwell_1984_1983.en.md`
-   **中文示例**: `Orwell_1984_1983.zh.md`

## 示例结构

```
summaries/
├── Orwell_1984_1983.en.md
├── Orwell_1984_1983.zh.md
├── Hawking_ABriefHistoryOfTime_1988.en.md
└── README.md
```

## 贡献

我们欢迎为库中的任何书籍撰写摘要！请：
- 保持摘要简明且信息丰富
- 尽量避免剧透（或在摘要中明确标注可能的剧透）
- 关注主题、写作风格与关键要点
- 使用可读且友好的语气
