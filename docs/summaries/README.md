# Book Summaries

This folder contains brief summaries and overviews of books available in the library.

## Purpose

Book summaries help readers:
- Quickly understand what a book is about
- Decide if a book matches their interests
- Get an overview before diving into the full text
- Refresh their memory about a book they've read

## Format

Each summary should include:
- Book title and author
- Publication year
- Key themes
- Brief overview (3-5 paragraphs)
- Target audience

See the [template](../templates/book-summary-template.md) for the recommended format.

## Naming Convention

Use the same naming as the book file, but with `.md` extension:
- Example: `Orwell_1984_1949.md`

## Contributing

We welcome summaries for any book in the library! Please:
- Keep summaries concise and informative
- Avoid spoilers when possible (or clearly mark them)
- Focus on themes, style, and key takeaways
- Write in an accessible, friendly tone
