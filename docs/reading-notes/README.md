# Reading Notes

[🇺🇸 English](./README.md) | [🇨🇳 中文](./README.zh-CN.md)

This folder contains detailed reading notes, insights, and highlights from books in the library.

## Purpose

Reading notes are personal reflections and detailed observations that:
- Capture key insights and learnings
- Highlight important quotes and passages
- Document questions and reflections
- Create a personal reference for future use

## Format

Reading notes are more flexible than summaries. They can include:
- Chapter-by-chapter notes
- Key quotes with page numbers
- Personal reflections and connections
- Questions raised by the reading
- Action items or applications

See the [template](../../templates/reading-notes-template.md) for a suggested format.

## Naming Convention

Use the format: `AuthorLastName_BookTitle_Year_NotesBy[YourName].md`
- Example: `Orwell_1984_1949_NotesByJohn.md`

This allows multiple people to share their notes on the same book.

## Contributing

Share your reading notes to help others learn! Please:
- Be thorough but organized
- Include page numbers for references (when applicable)
- Clearly distinguish between the author's ideas and your own thoughts
- Feel free to be personal - these are your notes!
