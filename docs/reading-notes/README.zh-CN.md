# 阅读笔记

[US English](./README.md) | [CN 中文](./README.zh-CN.md)

本文件夹包含有关库中书籍的详细阅读笔记、见解与摘录。

## 目的

阅读笔记是个人的反思与详细记录，旨在：
- 捕捉关键见解与学习要点
- 标注重要引用与段落
- 记录问题与思考
- 作为未来参考的个人资料

## 格式

阅读笔记相较于摘要更具灵活性，可包含：
- 按章节的笔记
- 带页码的关键引用
- 个人反思与关联
- 阅读过程中提出的问题
- 可执行的行动项或应用建议

建议格式请参见：[template](../../templates/./reading-notes-template.zh-CN.md)

## 命名约定

使用格式：`AuthorLastName_BookTitle_Year_NotesBy[YourName].md`
- 示例：`Orwell_1984_1949_NotesByJohn.md`

此约定便于多人对同一本书共享各自笔记。

## 贡献

分享你的阅读笔记，帮助他人学习！请：
- 详尽但保持条理
- 在适用时包含页码以便引用
- 清晰区分作者观点与个人想法
- 欢迎个人化表达——这些是你的笔记！
