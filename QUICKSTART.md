# Quick Start Guide

Welcome to E-Library! This guide will help you get started quickly.

## For Readers

### 1. Browse the Collection

Choose your preferred browsing method:
- **By Genre**: `books/by-genre/` - Fiction, Technical, Science, etc.
- **By Author**: `books/by-author/` - Find all books by an author
- **By Topic**: `books/by-topic/` - Machine Learning, Web Dev, etc.

### 2. Find Books

- Browse folder READMEs to see available books
- Check `docs/summaries/` for book overviews
- Use GitHub search to find specific titles or authors

### 3. Download

```bash
# Clone the entire repository
git clone https://github.com/TiiJeiJ8/E-Library.git

# Or download specific files through GitHub's web interface
```

## For Contributors

### Adding a Book (5 Steps)

1. **Fork** the repository on GitHub

2. **Add your book** to the appropriate folder:
   ```
   books/by-genre/[Genre]/YourBook.pdf
   ```

3. **Update the folder README** with book details

4. **Add a summary** (optional but appreciated):
   ```
   docs/summaries/YourBook.md
   ```

5. **Submit a Pull Request** with a clear description

### File Naming

Use this format: `AuthorLastName_BookTitle_Year.ext`

Example: `Orwell_1984_1949.epub`

### What Can You Contribute?

- ✅ Public domain books
- ✅ Creative Commons licensed books
- ✅ Books you have permission to share
- ✅ Book summaries and reading notes
- ✅ Documentation improvements
- ❌ Copyrighted books without permission
