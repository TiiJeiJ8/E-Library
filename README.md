# E-Library 📚

A GitHub repository for storing and organizing electronic book files (PDF, EPUB, MOBI, AZW3, etc.)—a simple, centralized space for your digital library.

## 📖 Overview

This repository provides a structured way to store, organize, and manage your collection of electronic books. Whether you're building a personal library or sharing resources with a team, E-Library offers an organized folder structure to keep your digital books easily accessible.

## 📁 Repository Structure

```
E-Library/
├── books/
│   ├── computer-science/      # Programming, algorithms, software engineering
│   ├── fiction/                # Novels, short stories, literary fiction
│   ├── non-fiction/            # History, biography, science, etc.
│   ├── technology/             # Tech guides, manuals, IT books
│   ├── business/               # Business, economics, management
│   ├── science/                # Natural sciences, mathematics, physics
│   ├── arts/                   # Art, music, design, photography
│   └── reference/              # Dictionaries, encyclopedias, manuals
├── CONTRIBUTING.md             # Guidelines for adding books
└── README.md                   # This file
```

## 🚀 Getting Started

### Cloning the Repository

```bash
git clone https://github.com/TiiJeiJ8/E-Library.git
cd E-Library
```

### Browsing Books

Navigate through the organized folders to find books by category. Each category folder contains relevant e-books in various formats.

### Adding Books

1. Fork this repository
2. Add your book file to the appropriate category folder
3. Follow the naming convention: `Author_Name - Book_Title.extension`
   - Example: `Martin_Fowler - Refactoring.pdf`
4. Create a pull request with a description of the book(s) added

For detailed guidelines, see [CONTRIBUTING.md](CONTRIBUTING.md)

## 📝 Supported Formats

- **PDF** - Portable Document Format
- **EPUB** - Electronic Publication (widely supported)
- **MOBI** - Mobipocket (Kindle-compatible)
- **AZW3** - Amazon Kindle Format
- **DJVU** - Document format for scanned documents
- **TXT** - Plain text files

## 🗂️ Organization Guidelines

### File Naming Convention

Use the following format for consistency:
```
Author_Last_Name - Book_Title.extension
```

Examples:
- `Knuth_Donald - The_Art_of_Computer_Programming.pdf`
- `Rowling_J.K. - Harry_Potter_and_the_Philosophers_Stone.epub`
- `Feynman_Richard - Surely_Youre_Joking_Mr_Feynman.pdf`

### Category Placement

- **Computer Science**: Programming languages, algorithms, data structures, software engineering
- **Fiction**: Novels, short stories, fantasy, sci-fi, literary fiction
- **Non-Fiction**: History, biography, self-help, true crime
- **Technology**: Technical manuals, IT guides, emerging tech
- **Business**: Management, entrepreneurship, finance, marketing
- **Science**: Physics, chemistry, biology, mathematics, astronomy
- **Arts**: Visual arts, music theory, design, photography
- **Reference**: Dictionaries, encyclopedias, handbooks, guides

## 💡 Tips

- Keep filenames descriptive and consistent
- Add subdirectories within categories if a category becomes too large
- Consider adding a `README.md` in category folders to list available books
- Use Git LFS (Large File Storage) for very large files if needed
